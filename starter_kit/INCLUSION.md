# 你的工具，让哪一类原本进不来的人第一次能用上量子计算？

题面第五节第 4 条的必答题。这份文档是 LoomQ 的答案，以及答案在代码里对应的位置。

---

## 答案：**有具体问题、但没有科班通道的人**

不是"不懂量子的人"——那太宽泛了。是这样一类具体的人：

> 一个做生态调查的研究生，手上有一个组合优化问题；
> 一个中学物理老师，想让学生亲眼看见"纠缠"而不是背定义；
> 一个独立设计师，想用真实的量子随机性生成图案；
> 一个转行做产品的工程师，想搞清楚量子计算到底能不能解决自己业务里的排班问题。

他们的共同点不是"笨"，是**没有那条通道**：
没有导师帮忙申请机时，没有同门告诉你 OriginIR 和 QCIS 的区别，
没人提醒你 `cu1` 在 Braket 里叫 `cp`。
这些不是智力门槛，是**信息与关系的门槛**——而这类门槛，历来对女性、
对跨学科背景、对非一线城市院校的人更高。

LoomQ 不试图教会他们量子力学。LoomQ 做的是把"我想要什么"和
"某台机器能听懂的指令"之间那段路铺平。

## 五道门槛，五个具体的拆法

### 门槛一：第一步就要装环境

**现状**：想跑第一个量子程序，先装 SDK、配 Python 版本、解决 wheel 冲突。
很多人死在这一步，而且不会告诉任何人。

**LoomQ 的做法**：核心零第三方依赖。`requirements.txt` 是空的。

```bash
python3 -m loomq tour
```

四步导览，每一步都真的跑一次电路——不是截图，是当场算出来的分布。
不联网、不注册、不装包。

→ 代码：[`loomq/tour.py`](loomq/tour.py)、[`loomq/sim/`](loomq/sim/)

### 门槛二：要先学会一种语言才能提问

**现状**：OpenQASM 不难，但它是一道**先修课**。
在你能问出第一个问题之前，你得先学会怎么问。

**LoomQ 的做法**：用中文说你想看到什么结果。

```
你：做一个 3 比特的最大纠缠态，并全部测量
```

LoomQ 返回：一句人话解释、可运行的 QASM、电路图、理论分布直方图，
以及一条"真跑一次"的命令。

关键在于**它不是把你的话丢给模型碰运气**：模型负责听懂你在说什么，
电路由 LoomQ 按教科书构造生成，并在返回给你之前用精确模拟器核对过。
你拿到的东西是被验证过的，不是被生成出来的。

→ 代码：[`loomq/agent/`](loomq/agent/)，设计见 [`ARCHITECTURE.md`](ARCHITECTURE.md) 第 7 节

### 门槛三：报错信息只对已经懂的人友好

**现状**：`ParseError: unexpected token` 对新手等于"你不属于这里"。

**LoomQ 的做法**：解析器的错误信息是产品功能，被当作产品功能来测试。

```
undeclared quantum register 'q' (line 1, column 3)
    H q[0]; CX q[0] q[1]
  hint: declare it first, e.g. `qreg q[2];`
```

```
gate cx acts on 2 qubit(s), got 1 (line 4, column 1)
    cx q[0];
  hint: check the operand order, e.g. `cx control, target;`
```

同一套诊断信息也是智能体纠错能力的燃料：修复失败时，
LoomQ 把**具体哪一行、什么问题**回传给模型，而不是让它盲猜。

→ 代码：[`loomq/errors.py`](loomq/errors.py)、
[`tests/test_qasm_frontend.py`](tests/test_qasm_frontend.py) 的 `DiagnosticTests`

### 门槛四：每家平台的黑话都不一样

**现状**：本源用 OriginIR，量旋用 SpinQit，Braket 用 OpenQASM 3。
学会一家不代表能用另一家。位序约定不同还会让你的结果悄悄错掉。

**LoomQ 的做法**：写一次，三家都能跑。

```bash
python3 -m loomq transpile bell.qasm --target all
```

位序在中间层统一归一化成 `c[n-1]…c[0]`（最右边是 `c[0]`），
厂商返回反了会被自动检测并纠正。

→ 代码：[`loomq/emitters/`](loomq/emitters/)、[`loomq/execution.py`](loomq/execution.py)

### 门槛五：看不见的东西没法理解

**现状**：一串 counts 说明不了什么。"纠缠"这个词你可以背下来，
但你不会**相信**它，直到你看见 `01` 和 `10` 一次都没出现。

**LoomQ 的做法**：每个结果都配电路图和分布直方图，
浏览器界面里是 SVG，终端里是 ASCII，两者出自同一份排布代码。

导览的第二步会明确指出来："注意，`01` 和 `10` 一次都没出现。
这就是纠缠——不是「两个都随机」，而是「两个一起随机」。"

→ 代码：[`loomq/diagram.py`](loomq/diagram.py)、[`loomq/web/`](loomq/web/)

## 三个用户体验任务（评测用）

工作人员可以用这三个任务检验"零基础用户五分钟内能不能跑出第一个量子程序"：

```bash
cd starter_kit
python3 -m loomq web        # 浏览器打开 http://127.0.0.1:8787/
```

1. **零知识入门**：点「第一次来？看 3 步演示」。
   预期：三个电路图 + 三张分布图，全部当场计算，不需要任何输入。
2. **一句话生成**：在输入框输入「做一个 4 比特的 GHZ 纠缠态并全部测量」。
   预期：解释 + 可运行 QASM + 电路图 + `0000` 与 `1111` 各 50% 的直方图；
   点「运行」拿到真实 counts；点「看三家平台的原生指令」看到三种方言。
3. **出错求助**：输入「我想制备一个贝尔态，但这段代码报错了，帮我修好：
   `H q[0]; CX q[0] q[1]`」。
   预期：LoomQ 指出问题（缺寄存器声明、门名大小写），
   给出修好的、模拟核对过的电路。

不配置模型服务时，任务 1 与所有电路功能仍然可用，界面会明确说明缺什么。

## 无障碍与包容性细节

不是事后补的，是写界面时就在的：

- **深色 / 浅色模式**跟随系统，两套配色都做过对比度检查；
- **键盘可达**：所有控件可 Tab 到达，焦点有清晰描边，`Ctrl+Enter` 提交；
- **屏幕阅读器**：SVG 电路图带 `role="img"` 和 `aria-label`，
  状态区 `aria-live="polite"`，示例按钮有可读文本；
- **`prefers-reduced-motion`**：关掉进度条动画；
- **零外部资源**：没有 CDN、没有外链字体、没有埋点。断网可用，也不上传任何东西；
- **中文优先**：界面、导览、智能体默认中文回复，英文提问则英文回答。

## 一句话收尾

这道题不奖励最懂量子的人，奖励让最多人能用上量子的人。

LoomQ 的赌注是：**门槛从来不在物理里，在工具链里。**
物理需要时间去学，而工具链只需要有人愿意把它拆掉。
