# LoomQ core: no third-party dependencies.
#
# The front end, the twelve-gate lowering passes, all three IR emitters, the
# reference statevector simulator, the L2 agent transport and the L3 compiler
# are written against the Python 3.10 standard library only. That is a design
# decision, not an omission: a submission that cannot install is a submission
# that scores zero, and every layer here has to run in a bare interpreter.
#
# Vendor SDKs are optional accelerators, pinned in requirements-backends.txt and
# loaded lazily by loomq/backends/. Install them to execute on the vendors' own
# simulators and on real hardware:
#
#     pip install -r requirements-backends.txt
#
# `python -m loomq doctor` reports which ones are present.
